# Flashcard Android App

A simple and interactive flashcard app built using Kotlin to help users learn and revise efficiently.

## Features
- Create and manage flashcards
- Flip cards to view answers
- Clean and simple UI
- Mobile-friendly design

## Tech Stack
- Kotlin
- Android Studio
- XML Layouts

## How to Run
1. Clone the repo
2. Open in Android Studio
3. Run on emulator or device
